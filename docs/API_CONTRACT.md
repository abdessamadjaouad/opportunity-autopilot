# Local API contract v1

All API routes use `/api/v1`. JSON timestamps are ISO 8601 UTC; UI formats Africa/Casablanca and keeps original deadline text/timezone. A successful list is a JSON array. Every record has `id`, `created_at`. Extra domain fields live in `data` internally but responses flatten them. Never render source HTML. Errors return `{detail: string}` with an appropriate HTTP status.

Authentication: `GET /session` returns `{authenticated, csrf_token?, owner?, setup_required, live_enabled:false}`. `POST /login {password}` returns that shape and an HttpOnly SameSite=Strict session cookie. Browser passwords go only to the same-origin local/HTTPS API. First password is set in terminal, never by an open registration route. Every mutation except login requires `X-CSRF-Token` from session and credentials same-origin. `POST /logout` clears session.

`GET /dashboard` returns `{counts:{opportunities,applications,needs_human,confirmed,uncertain}, controls, coverage:{registered,healthy,failed,last_check}, notifications:[], recent_opportunities:[]}`.

`GET /opportunities?search=&country=&track=&eligibility=&route=` returns records `{id,title,employer,country,track,route,url,availability,description,language,first_seen_at,last_seen_at,last_verified_at,source_posted_at,deadline,deadline_text,deadline_timezone,content_hash,fit,eligibility,relocation,assessment?,application_id?,application_state?,is_fixture:false}`. `POST /opportunities {url,title,employer,country?,track?,description?,language?,route?}` creates an UNVERIFIED manual lead and a discovered application. Read access to an official listing is required to verify it. Manual entry must never imply an open verified role.

`GET /opportunities/{id}` additionally returns `{occurrences:[],requirements:[],assessment,application,packets:[],tasks:[],timeline:[]}`. `POST /opportunities/{id}/verify` rechecks permitted public source. `POST /opportunities/{id}/assess` runs evidence-backed matching. `POST /opportunities/{id}/packet {family?,language?}` prepares immutable artifacts; response is packet with validations and blockers. `POST /opportunities/{id}/review {country?,track?,requirements?,relocation_evidence?,route?,destination?,evidence_url,note}` records owner evidence, invalidates assessments/packets, then reassesses; it does not manufacture external verification.

`GET /applications?search=&state=` returns `{id,opportunity_id,title,employer,country,state,updated_at,packet_id?,route,...}`. `GET /applications/{id}` includes timeline, packets, tasks, attempts and messages. `POST /applications/{id}/state {state,note}` supports interview/offer/rejected/withdrawn/skipped only, with recorded owner-reported evidence. `POST /applications/{id}/manual-submission {evidence,reference?}` records owner-reported manual submission and atomically cancels queued attempts, refusing an in-flight dispatch. `POST /applications/{id}/queue` re-evaluates current gates; disabled live mode returns an explicit hold, never sends. `POST /applications/{id}/reconcile` checks configured provider evidence.

`GET /human-tasks` returns `{id,application_id?,opportunity_id?,title,reason,question,priority,status,context:{url?,documents?,answers?,...},resolution?,created_at}`. `POST /human-tasks/{id}/resolve {resolution,answer_key?,answer_value?,context?}` records the answer and resumes through gates, retaining unresolved blockers. A note alone cannot confer eligibility or resolve unknown work rights.

`GET /profile` returns `{candidate:{id,name,revision,preferences},facts:[{id,key,label,value,status,sources:[],owner_correction,revision,category,employment_type?}],answers:[],revisions:[],unresolved_count}`. `POST /profile/import` explicitly reads configured read-only portfolio evidence. `PATCH /profile/facts/{id} {value,status:"confirmed",note}` records correction and new revision, invalidates dependent packets. `POST /profile/answers {key,value,context,sensitive:false,consent:false}` records reusable owner answer. `PATCH /profile/preferences` stores countries, tracks, contracts, salary/funding floor, citizenship, work authorizations, relocation/start windows and sensitive-disclosure preferences. Missing values remain unknown.

`GET /documents` returns packets `{id,application_id,title,status,language,family,manifest,validation,artifacts:[{id,filename,mime_type,sha256,size_bytes}],created_at}`. `POST /artifacts/{id}/ticket` returns `{url,expires_in:60}`; authenticated short-lived download route serves only validated artifact paths. `POST /profile/attachments` multipart upload `{kind,file}` accepts private PDFs only (transcript,certificate,language_test,paper); no alteration to the file. Approved reference data uses answer bank with disclosure consent.

`GET /sources` returns `{id,name,connector,url,board_id,enabled,permission_status,reviewed_at,poll_interval_seconds,last_success_at,next_check_at,status,error,failures,occurrence_count}`. `POST /sources {name,connector,url?,board_id?,permission_note?,poll_interval_seconds?}`; documented public API connectors can have reviewed read permission; generic feeds/pages require evidence of permission. `PATCH /sources/{id} {enabled?,poll_interval_seconds?}`. `POST /sources/{id}/poll` queues a durable safe poll. `GET /source-runs` returns recent records. `POST /discovery/email-alert {raw_email}` parses owner-imported alerts as unverified leads, never as receipts.

`GET /automation` returns `{controls,policy,policy_history:[],connections:[],budget:{daily_cents,monthly_cents,requests,tokens},jobs:[],source_runs:[],metrics,notifications:[]}`. `PATCH /controls {paused?,daily_cap?,daily_budget_cents?,monthly_budget_cents?,daily_request_cap?,daily_token_cap?,retention_days?}` changes operational controls; zero budget forbids paid work. `POST /policy {mode,allowed_countries,allowed_tracks,allowed_routes,allowed_domains,allowed_document_families,approved_answers?,daily_cap?,reviewed_packet_ids?,approve:false}` stores a revision; approving autopilot requires explicit UI acknowledgment, reviewed packets, profile reconciliation and deployment live switch. Draft policy editing works with no authority. `POST /connections/gmail/start` returns `{authorization_url}` when server OAuth configuration is present, otherwise a clear 409 unconfigured. `POST /connections/gmail/disconnect` discards encrypted credentials locally. `POST /notifications/{id}/read`. `POST /automation/tick` runs one safe durable scheduler tick. `POST /automation/digest` builds in-app daily digest; external notifications require owner configuration.

The UI should keep all implemented actions visible with clear validation/errors. Unconfigured live connections stay labeled; avoid fake charts or sample application counts. All fixture browser tests must explicitly identify simulator content and use a separate temporary database.
